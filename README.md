**PortfolioGen — Portfolio & Resume Builder**
*HTML, CSS, JavaScript, LocalStorage | GitHub*

* Developed **PortfolioGen**, a no-code career platform that allows users to create professional personal portfolios and ATS-friendly resumes through dedicated portfolio and resume builders.
* Built a dynamic **Portfolio Builder** with customizable sections for personal information, skills, education, experience, projects, social links, and other professional details.
* Implemented multiple professionally designed **portfolio templates**, allowing users to select a design and generate a personalized portfolio without manually writing HTML or CSS.
* Developed a complete **Resume Builder** with dynamic sections for personal details, career objective, education, technical skills, projects, experience, certifications, and achievements.
* Added **real-time resume preview**, allowing users to instantly see changes while entering or editing their information.
* Implemented dynamic **Add/Remove functionality** for education, projects, experience, and certifications using JavaScript and DOM manipulation.
* Added **resume section reordering**, allowing users to move sections up or down according to their preferred resume structure.
* Implemented **LocalStorage-based draft saving and restoration**, enabling users to continue working on their resume without losing previously entered information.
* Added **PDF-ready resume generation** through browser print functionality with an optimized A4 resume layout suitable for professional applications.
* Implemented secure client-side rendering practices using text escaping for user-provided content and safe URL handling for external links.
* Designed a consistent **black, white, and grey visual theme** with responsive layouts, reusable components, interactive buttons, form validation states, and mobile-friendly styling.
* Added deployment-ready portfolio generation so users can download their portfolio files and deploy them on static hosting platforms such as **GitHub Pages, Netlify, and Vercel**.
* Structured the application into separate portfolio and resume modules with reusable CSS and JavaScript, making the project easier to maintain and extend.
